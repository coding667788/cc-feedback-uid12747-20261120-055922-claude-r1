实现本地文件完整性监控的离线模拟器，使用合成文件快照和安全告警队列，不访问宿主文件。每台设备的监控清单固定其代数、基线版本、受保护路径、对象标识与 SHA-256。硬链接别名由合成对象表定义，同一对象可从多个受保护路径引用。变更输入包含批次与范围，每个完整批次要么更新整台设备的视图，要么保留原版。合法基线更新需要授权签名及已确认的观测范围，明确区分合法发布、内容变化、别名变化和数据缺口。

观测可并发分段上报，每段绑定设备代数、基线快照与采集批次，乱序允许，缺段不能误报全部文件消失。完成观测后先产生不可执行的预检，提交核对设备代数、当前签名授权、完整段集合及基线 CAS，在 SQLite 原子记录新可信视图、差异告警及幂等回执。过去未获授权的内容不会因为路径后来改名或旧基线回退而变为可信。

用独立进程固定采集串入设备重建、预检后另一个进程替换基线、缺段后晚到以及签发权撤销。真实终止自己的工作进程于告警写入未提交和已提交未回执两处，重启断言每个提交仅一份随版本固定的告警。提供独立只读参考模型，覆盖路径大小写折叠、同对象多别名、相同名字新对象和已批准内容撤销。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
